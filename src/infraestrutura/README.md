# Camada de Infraestrutura e Dados

Acesso a banco, logs e integrações externas.

- `repositorio/`: acesso ao PostgreSQL.
- `log-auditoria/`: tabela de auditoria somente de inserção.
- `adaptadores-canal/`: envio de notificações por push e e-mail.
- `gateway-mensageria/`: integração com WhatsApp e Telegram.
